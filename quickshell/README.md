# Quickshell Configuration

This is a quickshell configuration ported from waybar, with pywal theming support.

## Features

- Hyprland workspace indicator with icons
- Active window title display
- System monitoring widgets (CPU, memory, temperature)
- Network status
- Battery indicator with critical warning animation
- Brightness control display
- Audio/volume control widget
- System tray
- Clock
- **Volume popup overlay** - Shows when volume changes with visual feedback

## Installation

1. Install quickshell: Follow instructions at https://quickshell.outfoxxed.me

2. Link or copy this configuration:
   ```bash
   ln -s ~/dotfiles/quickshell ~/.config/quickshell
   ```

3. Set up pywal color integration:

   The configuration uses pywal colors from a generated Colors.qml file. You need to either:

   **Option A: Symlink (recommended)**
   ```bash
   # After running wal, symlink the generated file
   ln -sf ~/.cache/wal/colors-quickshell.qml ~/.config/quickshell/Colors.qml
   ```

   **Option B: Post-wal hook**
   Create a wal hook to copy the file automatically after color generation.

4. The quickshell config will launch automatically via hyprland.conf

## Theming

Colors are loaded from the `Colors.qml` singleton, which should be generated by pywal using the template in `~/dotfiles/wal/templates/colors-quickshell.qml`.

When you run `wal -i <image>`, it will generate `~/.cache/wal/colors-quickshell.qml` which needs to be accessible to quickshell.

## Volume Popup

The volume popup will automatically show when:
- Volume is changed via media keys
- Volume is scrolled on the audio widget
- Mute state is toggled

The popup displays for 2 seconds and shows:
- Current volume icon
- Volume percentage
- Visual volume bar
- Mute status (if muted)
