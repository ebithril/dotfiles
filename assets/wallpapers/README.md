# Theme Wallpapers

This directory contains wallpapers for each theme in the quickshell configuration.

## Required Wallpapers

Add wallpaper images with these names:
- `solarized.jpg` - Wallpaper for Solarized Dark theme
- `onepiece.jpg` - Wallpaper for One Piece theme
- `brynas.jpg` - Wallpaper for Brynäs theme

## Supported Formats

You can use any image format supported by hyprpaper:
- `.jpg` / `.jpeg`
- `.png`
- `.webp`

If you use a different format, update the wallpaper path in `quickshell/Theme.qml`.

## How It Works

When you switch themes in the control center, quickshell automatically changes the wallpaper using hyprpaper.
